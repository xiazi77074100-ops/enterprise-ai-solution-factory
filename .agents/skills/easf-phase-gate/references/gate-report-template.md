```markdown
# ゲート報告 G<id>（Phase <n>）

| 項目 | 内容 |
|---|---|
| コミット | <SHA>（ブランチ） |
| 作成日 | YYYY-MM-DD |

| タスク ID | 内容 | 証跡のパス | 状態 |

（jp-dev-standards の試験成績の表）

## 9. 次のフェーズの提案（承認を求めるタスク ID）
```
